# Phase 10 Freeze — Issue Detail Modules

## Scope

Purpose:
Add collaboration features to issues.

Modules:

* comments
* activity history
* attachments

Issue Core, Workflow, Board, and Sprint behavior already exist and are out of scope.

---

## Architecture

Issue Core:

* apps/issues

Comments:

* apps/issues

Activity:

* apps/issues

Attachments:

* apps/issues

Reads:

* selectors

Writes:

* services

Views:

* thin only

Forbidden:

* business logic in views
* inline permission checks
* board logic
* workflow logic

---

# Comments

## Model

IssueComment

Fields:

* id
* issue (FK)
* author (FK User)
* body
* created_at
* updated_at

Rules:

* issue required
* author required
* body required
* trim whitespace
* empty comment forbidden

Permissions:

* can_view_issue()
* can_edit_issue()

Supported:

GET comments
POST comment
PATCH comment
DELETE comment

Delete:
soft delete not required
hard delete allowed

---

# Activity History

Purpose:
Audit user-visible issue events.

## Model

IssueActivity

Fields:

* id
* issue
* actor
* event_type
* old_value
* new_value
* created_at

Event types:

* status_changed
* assignee_changed
* sprint_changed
* comment_added
* comment_deleted
* attachment_added
* attachment_deleted

Rules:

* append-only
* never editable
* never deleted

Supported:

GET activity only

No write API.

Generated by services.

Slice 10.8 (service-layer generation):

* status_changed from workflow transition service
* sprint_changed from issue sprint assignment services
* assignee_changed from issue update service
* comment_added and comment_deleted from comment service

---

# Attachments

## Model

IssueAttachment

Fields:

* id
* issue
* uploaded_by
* file
* created_at

Rules:

* issue required
* uploaded_by required

Permissions:

* can_view_issue()
* can_edit_issue()

Supported:

GET attachments
POST attachment
DELETE attachment

No versioning.

---

# API Scope

Comments:

GET /api/issues/{id}/comments
POST /api/issues/{id}/comments
PATCH /api/comments/{id}
DELETE /api/comments/{id}

Activity:

GET /api/issues/{id}/activity

Attachments:

GET /api/issues/{id}/attachments
POST /api/issues/{id}/attachments
DELETE /api/attachments/{id}

---

# Out of Scope

* mentions
* reactions
* threaded comments
* rich text editor
* notifications
* realtime updates
* watchers
* followers
* approvals
* file versioning
* image annotations
